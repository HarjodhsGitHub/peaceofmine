# PeaceOfMine operator

Dashboard and ROS gateway for the retained vehicle, payload, ADC and GNSS.
See [workspace setup](../../docs/setup.md), [hardware](../../docs/hardware.md),
[calibration](../../docs/calibration.md) and [interfaces](../../docs/interfaces.md).

```bash
ros2 launch peaceofmine_operator operator_sim.launch.py
```

Both operator launch commands, `/ws`, HTTP/TLS and saved settings remain supported.
